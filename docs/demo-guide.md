- 首选 PublicNode 通过，候选业务调用 1 次，没有备用切换；参考 RPC 8 次、探测 2 次、OSV 请求 1 次。

“实测记录回放”表示历史观测，不是打开文件后重新查询，也不代表当前余额。参考与候选运营方有重叠；RPC 交叉核对不等于密码学状态证明。摘要完整性校验不替代来源签名。原始 JSON 中保留真实观察时间，影片画面不显示计时器。

## 宣传片的内容

以武汉两江、江汉关、桥梁与封样印记为原创视觉意象，从“托付需要验收”引出工具准入与数据验收。茶港属于产品类比，不宣称未经查证的历史检验制度。

影片依次解释：为何有响应还不够；地址、区块与金额如何逐项核对；如何在原批准范围内限制切换；已跑通哪些功能；证据完整性与数据真实性有什么区别。首选失败与切换作为规则和受控故障测试介绍，未写成本次成功实测的事件。

成效仅引用留档：一个真实余额核验闭环、16 份原件、10 个生产依赖查询 OSV。未使用未经测量的提效比例、准确率、用户规模或已上链宣传。当前是本地只读 ETH 余额 MVP，PI 模型与链上发布仍属后续工作。

## 交互体验

输入前不预填委托，不显示结果或证据。点击“填入示例”只填写输入；提交后才逐阶段解析，批准后开始案例验收。可选择正常、错区块、错金额、全部失败、参考冲突、限流、清单变化共七种分支。停止后不会继续推进；新建任务清空内容。

交互页使用明确标注的构造案例。本地规则确实解析输入与计算校验，但案例余额不代表所输入地址的真实余额。未调用模型，不展示或编造模型内部思维。下载文件使用 `jianghan-offline-demo/v1` 与本地 SHA-256，不能作为真实服务信誉证据。

## 开发与验证

- `pnpm build:demos`：从 `web/demo-src/` 与 `web/film-src/` 生成三份单文件 HTML。构建时校验实测报告、原件摘要及引用，并核对宣传中引用的计数；来源变化会要求复核文案。
- `pnpm test:demos`：浏览器检查空首屏、逐阶段处理、批准、停止、案例摘要、文件下载、实测证据原样导出、片长、暂停/回退/结束、桌面/手机布局、无可见时间码、无外部请求。
- `pnpm export:films`：逐帧导出两份 1600×900、12 fps 的 VP8 WebM。画面保留中文字幕与来源，不录制播放器控件。需要本地 Playwright 与支持 VP8 的 FFmpeg，可配置 `PLAYWRIGHT_MODULE`、`EDGE_PATH`、`FFMPEG_PATH`。
- `pnpm verify:bundle artifacts/live/ui-bundle.json`：在独立进程复核完整证据。
