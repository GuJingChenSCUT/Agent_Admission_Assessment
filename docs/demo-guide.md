# 江汉验关 · 离线演示使用说明

## 两个文件

- `web/demo.html`：交互演练版。可直接双击打开，输入自己的任务；输入前不预填 prompt，不生成结果和证据。
- `web/demo-film.html`：1 分 50 秒的 HTML 定时放映版。点击“开始播放”，演示输入、批准、错块拒绝、备用切换、证据和篡改检测。可暂停、倍速、拖动进度、章节跳转与全屏。没有音轨，使用中文字幕讲解。

两份文件各自包含完整脚本、样式和 SVG，无需安装、无需启动后端、无需网络；复制到另一台电脑仍可打开。保留在同一个文件夹可互相跳转。系统未安装华文中宋时会使用宋体等本地回退字体。

运行正式本地服务器后，也可访问 `/demo.html` 和 `/demo-film.html`。页面 `/` 仍是真实后端工作台；演示页不会请求 `/v1/tasks`、RPC、OSV 或模型。

## 交互版推荐演示顺序

1. 打开页面，展示空白任务输入和空执行记录。
2. 点击“填入示例”，或粘贴以下输入。此时仍不执行：

   ```text
   请核验 0x2222222222222222222222222222222222222222 在以太坊主网的原生 ETH 余额，使用执行时 finalized 区块；首选失败时允许切换一次备用服务。
   ```

3. 选择默认“首选区块不符 → 备用通过”，点击“提交演练任务”。约 6 秒内逐步显示范围识别、地址识别和约束整理。
4. 检查地址、网络、区块策略与预算，点击“批准本次演练”。不批准会停留等待。
5. 观察固定参考 → 准入检查 → 首选调用 → 区块拒绝 → 备用切换 → 验收通过 → 证据生成。默认批准后的流程约 49 秒，各阶段保留阅读时间。
6. 点击“核对原件”和“篡改副本试验”，再下载演练 JSON。SHA-256 是浏览器实际计算的摘要，不是固定字符串；篡改试验只改副本。

演练情节共 7 种：正常、错区块、错金额、全部失败、参考冲突、限流、清单变化。取消“允许一次备用切换”，或在 prompt 中写“不要切换”，会限制为单候选。执行中可停止，也可新建空白任务；旧步骤不再继续。

缺少地址、多地址、缺少余额意图、USDT、转账或任意 URL 等输入会要求调整，不强行播放成功流程。地址解析及验收规则在本地运行；输入地址不同，范围与演练证据也会不同，但余额始终是明确标注的构造样本，**不反映该地址真实余额**。

## 定时版时间线

| 时间 | 内容 |
| --- | --- |
| 00:00–00:08 | 东方茶港意象，约定、验收与留据 |
| 00:08–00:18 | 模拟输入 prompt |
| 00:18–00:24 | 逐步解析范围 |
| 00:24–00:38 | 展示范围、脚本演示批准动作 |
| 00:38–01:01 | 固定参考、准入、首选交付与错块拒绝 |
| 01:01–01:24 | 有界切换备用，逐项验收 |
| 01:24–01:34 | 封存报告，出现已验收样本结果 |
| 01:34–01:45 | 核对原件，修改副本并检出篡改 |
| 01:45–01:50 | 结束字幕 |

空格播放/暂停，左右方向键移动 5 秒；焦点位于输入框或按钮时保留控件原有键盘行为。切换到其他浏览器标签页会暂停，避免错过内容。加 `?autoplay=1` 可自动开始，例如 `http://127.0.0.1:8787/demo-film.html?autoplay=1`。

## 演示边界

工作状态展示的是可核查的操作与规则摘要，不是模型内部思维。演示全程使用构造样本，未调用 PI、RPC、OSV、钱包或主网；不会把动画声称为模型推理。演练证据使用独立 schema `jianghan-offline-demo/v1` 和 SHA-256，不应被当成真实服务信誉或生产 API 的 Keccak/JCS 报告。

浏览器不支持 Web Crypto 时会明确提示无法核对摘要，不伪造校验成功。

## 开发与验证

修改 `web/demo-src/` 后运行 `pnpm build:demos` 生成两个单文件 HTML。生成时从现有工作台复用原创江汉关 SVG，并计算内嵌脚本的 CSP 摘要。`pnpm test:demos` 使用 Playwright 检查单文件打开、逐阶段推进、批准等待、停止隔离、证据下载、定时跳转、手机排版及零外部请求。可用 `PLAYWRIGHT_MODULE` 和 `EDGE_PATH` 指定本地浏览器测试环境。
