# 异常场景、恢复与验收追踪

版本 0.2。共 57 项已识别场景，全部为 DESIGN_REQUIRED。不是已执行测试或风险穷尽证明。SC- 为场景编号；D01–D12 为图编号。

## 任务与授权

### SC-T01 · 需求缺地址或有多个地址

- **检测：** TaskDraft 编译器
- **决定：** 补答，不创建执行命令
- **期望状态：** NEEDS_INPUT
- **用户提示：** 请明确本次核验地址
- **恢复：** 用户补答，增加 revision
- **保留证据：** 缺失字段、revision、无调用记录
- **责任人：** Control/Agent
- **验收方法：** 无地址输入后检查 providerCalls=0
- **追踪：** D02, D05；AT-T01；DESIGN_REQUIRED

### SC-T02 · ERC20、其他链、转账或任意 URL

- **检测：** 范围编译器
- **决定：** 拒绝未支持范围
- **期望状态：** 不生成可批准 TaskSpec
- **用户提示：** 当前只支持原生 ETH 余额只读核验
- **恢复：** 修改需求后重建提案
- **保留证据：** UNSUPPORTED_SCOPE 与解析范围
- **责任人：** Control
- **验收方法：** 未支持意图无法生成 gateway ticket
- **追踪：** D02, D04；AT-T02；DESIGN_REQUIRED

### SC-T03 · 用户修改已展示的范围

- **检测：** revision/specHash 比较
- **决定：** 旧批准和 nonce 失效
- **期望状态：** AWAITING_APPROVAL 或 NEEDS_INPUT
- **用户提示：** 范围已变化，请核对新版本
- **恢复：** 重新批准新版本
- **保留证据：** 旧/新摘要、revision、事件
- **责任人：** Control/Web
- **验收方法：** 旧批准请求返回 409，未入队
- **追踪：** D05；AT-T03；DESIGN_REQUIRED

### SC-T04 · 批准重复点击或 ACK 丢失

- **检测：** owner+route+Idempotency-Key
- **决定：** 同键同体返回既有 Run
- **期望状态：** 当前持久状态
- **用户提示：** 正在核对原任务是否已获准
- **恢复：** 查原 task；必要时原键重试
- **保留证据：** 请求摘要、幂等记录、唯一 Run
- **责任人：** Control
- **验收方法：** 重复/并发批准只生成一个 outbox
- **追踪：** D05, D07；AT-T04；DESIGN_REQUIRED

### SC-T05 · 相同幂等键携带不同请求体

- **检测：** 幂等摘要比较
- **决定：** 409，不产生新动作
- **期望状态：** 当前状态不变
- **用户提示：** 该请求键已用于其他内容
- **恢复：** 更正客户端状态，不自动换键执行
- **保留证据：** 原/新请求摘要、traceId
- **责任人：** Control
- **验收方法：** 同键不同 hash 不签票据
- **追踪：** D05；AT-T05；DESIGN_REQUIRED

### SC-T06 · 跨 owner 读取/批准/停止/下载原件

- **检测：** 每个对象的归属校验
- **决定：** 拒绝，不泄露存在性或 nonce
- **期望状态：** 当前状态不变
- **用户提示：** 无权访问此任务
- **恢复：** 使用合法会话或任务
- **保留证据：** 访问主体、对象引用、拒绝原因
- **责任人：** Control
- **验收方法：** 第二账号不能获取任何私有报告
- **追踪：** D01, D05；AT-T06；DESIGN_REQUIRED

### SC-T07 · 票据过期、重放、caller 或参数不符

- **检测：** Gateway 验签及原子 jti 消费
- **决定：** 拒绝 dispatch
- **期望状态：** Attempt REJECTED
- **用户提示：** 本次调用授权无效
- **恢复：** 同范围重新评估并签新票据，计入预算
- **保留证据：** jti、绑定字段摘要、拒绝码
- **责任人：** Gateway
- **验收方法：** 重放及并发消费仅最多一次成功
- **追踪：** D04, D07；AT-T07；DESIGN_REQUIRED

### SC-T08 · 批准后策略禁用或新风险紧急收紧

- **检测：** policyEpoch 与当前 denylist
- **决定：** 撤销未消费票据，禁止放宽
- **期望状态：** QUARANTINED 或停止收尾
- **用户提示：** 安全策略已收紧，本次暂停
- **恢复：** 修复后生成新范围/批准
- **保留证据：** 策略版本、epoch、禁用原因
- **责任人：** Policy
- **验收方法：** 旧票据不能穿越安全禁用
- **追踪：** D04, D10；AT-T08；DESIGN_REQUIRED

## Agent

### SC-A01 · 模型连接未配置

- **检测：** 启动 readiness 与模型适配器
- **决定：** 阻断在线创建；不得伪装模型输出
- **期望状态：** 创建返回 CONFIGURATION_REQUIRED
- **用户提示：** 在线模型尚未配置
- **恢复：** 配置后重试；结构化模式需显式标注
- **保留证据：** 配置存在性，不记录秘密
- **责任人：** Agent
- **验收方法：** LIVE 创建不会返回 SAMPLE 提案
- **追踪：** D01, D11；AT-A01；DESIGN_REQUIRED

### SC-A02 · 模型超时或 429

- **检测：** 适配器计时和预算
- **决定：** 有限重试；超限失败
- **期望状态：** 创建失败或 Run FAILED
- **用户提示：** 模型暂不可用，尚未执行新工具
- **恢复：** 预算内重试；否则新任务
- **保留证据：** 请求次数、耗时、模型错误码
- **责任人：** Agent
- **验收方法：** 计入模型预算，停止入口仍可用
- **追踪：** D02, D11；AT-A02；DESIGN_REQUIRED

### SC-A03 · 模型输出不符合 schema 或猜测地址

- **检测：** 确定性编译器
- **决定：** 不批准非法结构
- **期望状态：** NEEDS_INPUT 或 INVALID_INPUT
- **用户提示：** 需要补充或修正范围
- **恢复：** 有限纠正一次或用户补答
- **保留证据：** 原提案私有、校验错误
- **责任人：** Agent/Control
- **验收方法：** 额外字段与猜测值不能进入 TaskSpec
- **追踪：** D02, D05；AT-A03；DESIGN_REQUIRED

### SC-A04 · 工具描述/响应包含越权指令

- **检测：** 文本隔离与工具允许表
- **决定：** 当数据处理；后端拒绝越权
- **期望状态：** 当前受控流程或 QUARANTINED
- **用户提示：** 服务内容含不可信指令，已限制处理
- **恢复：** 跳过可疑候选或结束
- **保留证据：** 摘要、来源、命中规则、工具审计
- **责任人：** Agent/Gateway
- **验收方法：** 诱导 shell、提预算、签名均无可调用权限
- **追踪：** D01, D04；AT-A04；DESIGN_REQUIRED

### SC-A05 · 模型循环调用或重复选择服务

- **检测：** 服务器模型/工具预算
- **决定：** 终止新模型动作
- **期望状态：** FAILED 或确定性报告完成
- **用户提示：** 已达到任务预算
- **恢复：** 不自动增加预算；用户另开任务
- **保留证据：** 回合、token、候选和调用计数
- **责任人：** Worker
- **验收方法：** 超过 4 回合/2 次候选调用被阻止
- **追踪：** D02, D04；AT-A05；DESIGN_REQUIRED

### SC-A06 · 解释包含无依据金额或错误引用

- **检测：** 报告事实引用校验
- **决定：** 丢弃解释，模板回退
- **期望状态：** 事实状态保持不变
- **用户提示：** 显示已核验事实与范围
- **恢复：** 重建确定性说明
- **保留证据：** 解释版本、事实 ID、失配原因
- **责任人：** Evidence
- **验收方法：** 虚构数字不进入正常结果或 PublicReport
- **追踪：** D08；AT-A06；DESIGN_REQUIRED

### SC-A07 · Agent 运行时自动暴露 shell 或自修改

- **检测：** 启动时能力清单比对
- **决定：** readiness 失败，拒绝运行
- **期望状态：** CONFIGURATION_REQUIRED
- **用户提示：** 运行能力超出获准配置
- **恢复：** 移除扩展后重新部署
- **保留证据：** 有效工具清单、构建版本
- **责任人：** Agent/Ops
- **验收方法：** 非五个允许工具导致发布阻断
- **追踪：** D01, D11；AT-A07；DESIGN_REQUIRED

## 网络

### SC-N01 · TLS 证书或主机校验失败

- **检测：** 受限 HTTP 客户端
- **决定：** 不关闭验证，不降级 HTTP
- **期望状态：** Attempt INCONCLUSIVE
- **用户提示：** 服务连接身份无法核对
- **恢复：** 允许的备用路线或隔离
- **保留证据：** TLS 原因码、origin、时间
- **责任人：** Gateway
- **验收方法：** 错误证书不能继续取得响应
- **追踪：** D04；AT-N01；DESIGN_REQUIRED

### SC-N02 · DNS rebinding、私有地址或云元数据目标

- **检测：** 实际连接地址约束
- **决定：** 连接前拒绝
- **期望状态：** Attempt REJECTED
- **用户提示：** 服务目标不符合网络策略
- **恢复：** 管理员修正登记，用户不可放行
- **保留证据：** 解析集合、实际目标、规则
- **责任人：** Network
- **验收方法：** 只校验域名而实际连接私网的测试必须失败
- **追踪：** D04；AT-N02；DESIGN_REQUIRED

### SC-N03 · 跨 origin 重定向或 metadata URL

- **检测：** 出口策略与逐跳校验
- **决定：** 默认不跟随；不得携带原令牌
- **期望状态：** Attempt REJECTED
- **用户提示：** 服务跳转超出允许范围
- **恢复：** 管理员新增独立配置后重试
- **保留证据：** Location 摘要、目标、拒绝码
- **责任人：** Network
- **验收方法：** 令牌不流向重定向目标
- **追踪：** D04；AT-N03；DESIGN_REQUIRED

### SC-N04 · JSON 超大、压缩膨胀、超深或重复 key

- **检测：** 流式字节/解压/解析限制
- **决定：** 中止并记录无效数据
- **期望状态：** Attempt FAILED 或 INCONCLUSIVE
- **用户提示：** 响应超出安全处理范围
- **恢复：** 可用备用服务；不提高限额
- **保留证据：** 字节计数、内容摘要、解析码
- **责任人：** Gateway
- **验收方法：** 1 MiB 与深度上限触发后不继续缓冲
- **追踪：** D04；AT-N04；DESIGN_REQUIRED

### SC-N05 · 连接超时、半开、断流或读取中断

- **检测：** 请求 deadline 与完整性检查
- **决定：** 不假装得到空余额；计入已提交调用
- **期望状态：** Attempt INCONCLUSIVE
- **用户提示：** 服务响应不完整或超时
- **恢复：** 同快照获准备用；无路则 QUARANTINED
- **保留证据：** dispatch、耗时、已收字节、错误
- **责任人：** Gateway
- **验收方法：** 超时不返还已消费预算，不重用 jti
- **追踪：** D02, D07；AT-N05；DESIGN_REQUIRED

### SC-N06 · 服务 429 或 5xx

- **检测：** HTTP/RPC 分类
- **决定：** 候选调用不盲目重发
- **期望状态：** Attempt INCONCLUSIVE
- **用户提示：** 服务暂不可用
- **恢复：** 使用获准备用；新尝试计预算
- **保留证据：** 状态码、Retry-After、尝试记录
- **责任人：** Gateway
- **验收方法：** 自动库重试不能使实际调用超过 2 次
- **追踪：** D02, D04；AT-N06；DESIGN_REQUIRED

### SC-N07 · 浏览器事件流断开或消息乱序

- **检测：** sequence、游标与任务查询
- **决定：** 保持最后状态并标记连接过期
- **期望状态：** 客户端 DISCONNECTED；Task 不改写
- **用户提示：** 连接已中断，显示的是上次状态
- **恢复：** 按游标续读并查询当前 Task
- **保留证据：** 事件序号、更新时间
- **责任人：** Web
- **验收方法：** 乱序/重复事件不能把终态倒退成运行中
- **追踪：** D05；AT-N07；DESIGN_REQUIRED

### SC-N08 · 用户停止时鉴权过期或控制请求失败

- **检测：** 停止响应与会话校验
- **决定：** 不显示已停止
- **期望状态：** 客户端 STOP_ACK_UNKNOWN
- **用户提示：** 停止请求尚未确认
- **恢复：** 恢复认证并查询原任务；控制路径仍优先
- **保留证据：** stop 请求 ID、响应状态、当前任务
- **责任人：** Web/Control
- **验收方法：** 网络失败不直接写本地 CANCELLED
- **追踪：** D05, D06；AT-N08；DESIGN_REQUIRED

## 数据

### SC-D01 · 两个参考源链 ID 或区块 hash 冲突

- **检测：** Reference resolver
- **决定：** 不使用多数掩盖冲突
- **期望状态：** QUARANTINED
- **用户提示：** 参考来源不一致，暂不能判断
- **恢复：** 修复来源后新任务
- **保留证据：** 各参考原件、运营者、区块 hash
- **责任人：** Data
- **验收方法：** 参考冲突时 providerCalls=0
- **追踪：** D03；AT-D01；DESIGN_REQUIRED

### SC-D02 · finalized 头偏差超过配置窗口

- **检测：** 头高度与源健康检查
- **决定：** 不退回 latest
- **期望状态：** QUARANTINED
- **用户提示：** 参考节点同步状态不满足策略
- **恢复：** 修复节点或等待后新任务
- **保留证据：** 两端高度、窗口、采集时间
- **责任人：** Data
- **验收方法：** 超窗时不能构造 PASS Snapshot
- **追踪：** D03；AT-D02；DESIGN_REQUIRED

### SC-D03 · 同一参考区块的余额仍不一致

- **检测：** 两份精确 wei 比较
- **决定：** 不凭候选多数判真
- **期望状态：** QUARANTINED
- **用户提示：** 同区块参考余额不一致
- **恢复：** 排查独立性与节点后重试
- **保留证据：** 两份数量及相同 hash
- **责任人：** Data
- **验收方法：** 参考数量冲突时无 acceptedFact
- **追踪：** D03；AT-D03；DESIGN_REQUIRED

### SC-D04 · 服务明确声明错误区块

- **检测：** PROVIDER_DECLARED 绑定核对
- **决定：** 拒绝快照声明，跳过跨区块余额比较
- **期望状态：** Attempt FAILED
- **用户提示：** 返回声明不属于本次目标区块
- **恢复：** 同 Snapshot 备用候选
- **保留证据：** 期望/声明 blockHash、bindingKind
- **责任人：** Verifier
- **验收方法：** 错误块不同时再报虚构余额错误
- **追踪：** D03；AT-D04；DESIGN_REQUIRED

### SC-D05 · 原生 RPC 仅返回数量，或旧值恰好相同

- **检测：** 适配器 bindingKind 分类
- **决定：** 只声称请求绑定与数值一致性
- **期望状态：** 按参考对照决定；不产生 PROOF_VERIFIED
- **用户提示：** 未提供密码学状态证明
- **恢复：** 后续可增加可信区块头与证明方案
- **保留证据：** 原始 RPC 请求/响应、请求 hash
- **责任人：** Verifier
- **验收方法：** 自身附加的 blockHash 不能升级为服务证明
- **追踪：** D03, D08；AT-D05；DESIGN_REQUIRED

### SC-D06 · 地址/资产/chainId 或整数格式错误

- **检测：** 规范化与精度校验
- **决定：** 确定性拒绝，不做浮点补正
- **期望状态：** Attempt FAILED
- **用户提示：** 返回内容不符合本次查询范围
- **恢复：** 获准备用或结束
- **保留证据：** schema 错误、范围和原件摘要
- **责任人：** Verifier
- **验收方法：** 溢出、浮点、错误地址与负数均被拒绝
- **追踪：** D03, D04；AT-D06；DESIGN_REQUIRED

### SC-D07 · OSV 限流、缺页、超时、缓存过期

- **检测：** 完整性和 fetchedAt 策略
- **决定：** 必需信息未知时阻断
- **期望状态：** QUARANTINED
- **用户提示：** 依赖公告检查尚未完成
- **恢复：** 后台有界续页/更新；不可静默略过
- **保留证据：** 分页 token 进度、源版本、时间
- **责任人：** Data
- **验收方法：** 只取得第一页不能显示无已知公告
- **追踪：** D10；AT-D07；DESIGN_REQUIRED

### SC-D08 · 锁文件版本无法确定或公告区间不清

- **检测：** 生态/包名/精确版本解析
- **决定：** 不按包名猜测安全性
- **期望状态：** QUARANTINED
- **用户提示：** 无法确认本次依赖版本的受影响情况
- **恢复：** 补齐锁文件或维护者资料
- **保留证据：** 锁文件 hash、版本、区间依据
- **责任人：** Inspection
- **验收方法：** unknown 版本不能返回依赖 PASS
- **追踪：** D04, D10；AT-D08；DESIGN_REQUIRED

### SC-D09 · 远程 SBOM 缺失或无法绑定真实部署

- **检测：** 来源分类与策略 required 标志
- **决定：** 可选缺失显示未验证；必需缺失阻断
- **期望状态：** 可继续或 QUARANTINED
- **用户提示：** 远程部署来源未验证
- **恢复：** 补部署证明；不能用客户端锁文件顶替
- **保留证据：** VERIFIED_ARTIFACT/PROVIDER_DECLARED/NOT_AVAILABLE
- **责任人：** Inspection
- **验收方法：** 两种策略分别验收，不能一律放行或全拒
- **追踪：** D04, D10；AT-D09；DESIGN_REQUIRED

### SC-D10 · 同一公告出现在 OSV/GHSA/CVE 多个入口

- **检测：** aliases 与上游 provenance 去重
- **决定：** 去重并保留来源链

## 运行与恢复

### SC-O01 · 数据库写失败、磁盘满或损坏

- **检测：** readiness、事务返回、存储完整性
- **决定：** 冻结新 dispatch 和签名；不能假 ACK
- **期望状态：** 无可靠新终态，客户端状态未知
- **用户提示：** 服务无法持久化本次操作
- **恢复：** 运维恢复后核查原任务
- **保留证据：** 错误码、最后成功提交位置
- **责任人：** Ops
- **验收方法：** 停止落库失败时不返回已确认停止
- **追踪：** D06, D07, D11；AT-O01；DESIGN_REQUIRED

### SC-O02 · 工作器在票据消费前退出

- **检测：** lease 与 dispatch 记录
- **决定：** 新代际恢复未完成命令
- **期望状态：** 当前 Run 恢复执行
- **用户提示：** 任务恢复中
- **恢复：** 重新核对 scope/epochs 后调用
- **保留证据：** leaseGeneration、jti、未消费证明
- **责任人：** Worker
- **验收方法：** 恢复不创造重复 Run
- **追踪：** D07；AT-O02；DESIGN_REQUIRED

### SC-O03 · 票据已消费但响应未落库时退出

- **检测：** DISPATCH_COMMITTED 与响应缺口
- **决定：** 承认外部结果未知；预算不退款
- **期望状态：** Attempt INCONCLUSIVE
- **用户提示：** 原调用结果未知
- **恢复：** 同范围新票据备用或隔离
- **保留证据：** dispatch 时间、预算、恢复原因
- **责任人：** Worker
- **验收方法：** 不能复用原 jti 自动重发
- **追踪：** D07；AT-O03；DESIGN_REQUIRED

### SC-O04 · 响应已存但事实尚未提交时退出

- **检测：** 原件摘要与验证记录
- **决定：** 重算确定性验收
- **期望状态：** 按校验结果进入终态
- **用户提示：** 正在恢复已收到的结果
- **恢复：** 不再访问候选服务
- **保留证据：** 原件 hash、规则版本、提交守卫
- **责任人：** Worker/Verifier
- **验收方法：** 恢复不得增加 providerCalls
- **追踪：** D07；AT-O04；DESIGN_REQUIRED

### SC-O05 · 旧工作器在新租约后仍提交

- **检测：** leaseGeneration fencing
- **决定：** 拒绝旧代际消费和提交
- **期望状态：** 当前 Run 不被旧进程改写
- **用户提示：** 显示当前有效运行状态
- **恢复：** 由当前租约继续
- **保留证据：** 旧/新代际、拒绝原因
- **责任人：** Worker
- **验收方法：** 双工作器竞争只能一方提交
- **追踪：** D04, D07；AT-O05；DESIGN_REQUIRED

### SC-O06 · 停止与成功提交同时发生

- **检测：** 数据库 CAS 的提交顺序
- **决定：** 先提交的合法转换胜出
- **期望状态：** SUCCEEDED 或 STOP_REQUESTED/CANCELLED
- **用户提示：** 展示后端确定状态
- **恢复：** 晚到结果丢弃或返回已有成功
- **保留证据：** 事务顺序、epochs、事件
- **责任人：** Control/Worker
- **验收方法：** 同时触发两种顺序都验证
- **追踪：** D06；AT-O06；DESIGN_REQUIRED

### SC-O07 · 系统时间跳变或时钟偏差

- **检测：** UTC 记录与单调 deadline
- **决定：** 超范围凭据不继续使用
- **期望状态：** QUARANTINED 或鉴权拒绝
- **用户提示：** 时间条件不满足本次授权
- **恢复：** 修复时钟后重新签发，不改旧记录
- **保留证据：** 时间源、偏差、过期值
- **责任人：** Ops
- **验收方法：** 向后调墙钟不能延长运行预算
- **追踪：** D04, D07；AT-O07；DESIGN_REQUIRED

### SC-O08 · 未分类异常或未知错误码

- **检测：** 顶层异常边界与状态事务
- **决定：** 停止新动作，保留可诊断原因
- **期望状态：** FAILED 或 QUARANTINED；无法落库则未知
- **用户提示：** 任务未能完成，提供 traceId
- **恢复：** 分类复核后才能新任务
- **保留证据：** 已完成阶段、traceId、脱敏错误
- **责任人：** Worker
- **验收方法：** 异常不落入默认 ALLOW 分支
- **追踪：** D02, D07；AT-O08；DESIGN_REQUIRED

## 区块链与证据

- **检测：** 已存 signed bytes 与 txHash
- **决定：** 按原 hash 核查，拒绝新无关 nonce
- **期望状态：** UNKNOWN
- **用户提示：** 登记结果尚不明确
- **恢复：** 有界查询或同一原始交易恢复
- **保留证据：** 原 txHash、nonce、bytes 摘要
- **责任人：** Chain
- **验收方法：** 超时不能重复创建第二笔登记
- **追踪：** D09；AT-B03；DESIGN_REQUIRED

### SC-B04 · 交易明确 revert 或事件不匹配

- **检测：** receipt 与目标事件解码
- **决定：** 不显示登记成功
- **期望状态：** FAILED
- **用户提示：** 交易失败或记录不匹配
- **恢复：** 修复后另建显式 publication job
- **保留证据：** receipt status、address、topics、logIndex
- **责任人：** Chain
- **验收方法：** 只看 receipt.status=1 不足以 CONFIRMED
- **追踪：** D09；AT-B04；DESIGN_REQUIRED

### SC-B05 · 确认前链重组或 RPC 分歧

- **检测：** 当前 canonical hash 对照
- **决定：** 继续核查，保留不确定性
- **期望状态：** CONFIRMING 或 UNKNOWN
- **用户提示：** 主链确认尚未闭合
- **恢复：** 按同一交易持续检查
- **保留证据：** 旧/新区块 hash、观察时间
- **责任人：** Chain
- **验收方法：** 不以单一 RPC 一次回应完成确认
- **追踪：** D09；AT-B05；DESIGN_REQUIRED

### SC-B06 · 曾确认记录后来脱离主链

- **检测：** 当前 AnchorObservation
- **决定：** 保留历史，当前标为 ORPHANED/UNKNOWN
- **期望状态：** Publication 历史不改；当前核验失败/未知
- **用户提示：** 该登记当前不在已核对主链上
- **恢复：** 复核同 tx 或新批准记录
- **保留证据：** checkedAt、旧/当前 blockHash
- **责任人：** Chain
- **验收方法：** 历史 CONFIRMED 不覆盖当前孤块观察
- **追踪：** D08, D09；AT-B06；DESIGN_REQUIRED

### SC-B07 · nonce 被其他 signer 作业占用或交易替换

- **检测：** 专用 signer nonce 管理
- **决定：** 停止猜测；核对同账户同 nonce
- **期望状态：** UNKNOWN 或明确 FAILED
- **用户提示：** 登记交易需要复核
- **恢复：** 仅按受控策略恢复；费用变更新授权
- **保留证据：** sender、nonce、原/替代 txHash
- **责任人：** Chain
- **验收方法：** 不能将不同 payload 的替代交易归属本报告
- **追踪：** D09；AT-B07；DESIGN_REQUIRED

### SC-B08 · 公开报告被篡改或预览后内容变化

- **用户提示：** 内容与原摘要不符
- **恢复：** 恢复原件或生成新报告再批准
- **保留证据：** 基准/实际摘要、报告版本
- **责任人：** Evidence
- **验收方法：** 改一位金额后旧批准不能使用
- **追踪：** D08, D09；AT-B08；DESIGN_REQUIRED

### SC-B09 · URI 丢失、内容过期或撤销

- **决定：** 各层独立给出不可用/失效
- **期望状态：** Verification UNKNOWN/FAIL
- **用户提示：** 内容不可用或记录已失效
- **恢复：** 允许重新取原件；新任务须重新验收
- **保留证据：** URI/内容摘要、到期、撤销事件
- **责任人：** Evidence
- **验收方法：** 链上 hash 存在不能冒充原文可访问
- **追踪：** D08；AT-B09；DESIGN_REQUIRED

### SC-B10 · 验证者密钥受损或主体解绑

- **检测：** 可信验证者配置与事件/身份追踪

- **期望状态：** 新发布 blocked；旧报告标记复核

### SC-B11 · 刷分、关联验证者或同名服务混淆

- **决定：** 不聚合成无条件安全分
- **期望状态：** 历史信号有限使用
